# 中印欧神话对比 4：国民性——三种"对人的想象"及其社会后果

> 能不能从神话读出民族性格？如果能，因果链在哪里？

**系列定位：** 第 4 篇（共 5 篇）。创世类型见第 1 篇，人神边界见第 2 篇，统治正当性见第 3 篇，时间观见第 5 篇。

## 核心问题

"中国人和希腊人不一样""印度人宿命、欧洲人好斗"——这类判断在通俗写作里常被包装成"民族性格"或"国民性"。它有道理吗？

**核心原因（本篇结论）：** 神话**不能**直接推出国民性；能推出的，是"一个社会持续不断地从神话里取用什么"。国民性不是神话的产物，而是神话被反复征用的产物。要谈国民性，必须先回答三个问题：**谁在何时、为了什么、征用了哪一段神话。**

本篇分三步：先处理概念（国民性是什么、从哪来、争议在哪）；再给出三套神话里各自包含的"对人的想象"；最后说明每一种想象在历史上**经由什么制度中介**才产生了可观察的社会后果。

## 一、先处理概念：国民性是一个被制造出来的范畴

### 1.1 三条互不相干的论证线

讨论"国民性"时，至少混着三条不同性质的线：

| 线 | 内容 | 典型文献 |
|---|---|---|
| 描述性民族心性 | "英国人如何如何""印度人如何如何" | 19 世纪游记与殖民统计；H. G. Wells《欧洲人的心智》类著作 |
| 规范性国民性 | "我们要塑造什么样的国民" | 梁启超《新民说》(1902)；严复的译介；尼采"超人"论 |
| 批判性国民性 | "我们的国民性有问题，需要被改造" | 鲁迅自 1920 年代起的《坟》《热风》诸篇；殖民地知识分子的自我批判 |

这三条线互相借用材料，却不共享结论。批判性国民性在 20 世纪的中国尤其发达，其前提恰恰是：**国民性被判定为"病"，而病可以被疗治**——这已经是一个高度现代的、由社会达尔文主义与新文化运动共同提供的框架。

### 1.2 为什么"从神话读国民性"这一步是危险的

四条方法论理由，来自神话学、人类学与科学哲学的主流讨论：

1. **神话不是现实的镜像，而是行动的章程。** 马林诺夫斯基（Bronisław Malinowski, 1926）提出神话的功能是"为现存的社会制度与生活规程提供正当性"——它是被使用的，不是被反映的。既然是被使用的，它反映的是**主张**，不是**实况**。任何社会都可以主张一整套关于人的说法。
2. **神话比民族更古老。** 荷马早于英国、吠陀早于印度这个国名、盘古的叙事层次晚得多却与华夏认同相连。用五千年的神话解释十九世纪才成型的民族国家，时间对不上。
3. **"传统"在现代被大规模发明。** 霍布斯鲍姆（Eric Hobsbawm, 1983）列举了英国仪典、威尔士民俗、诸多"古老的"国家仪式的现代发明过程——其中许多正是从既有神话里取材再包装的。
4. **范畴与实践互相塑造。** 哈金（Ian Hacking, 1999）提出"人的种类"（人类学范畴）与"人的实践"之间是循环的：分类改变实践，实践又改变分类。殖民时期对"印度人含混宿命"的描述，一旦成为统治话语，就会改变印度人的实际处境，再反过来印证这个描述。

### 1.3 神话与民族之间真正重要的连接点

与其说神话塑造国民性，不如说神话是**民族叙事的原材料库**。安德森（Benedict Anderson, 1983/1991）指出，民族是"想象共同体"，其维系机制之一正是"同源的过去"——被共同记住、且被想象为共享的过去。神话在其中的作用是提供**可被共享的、超越个人寿命的时间纵深**（共同祖先、共同创世、共同灾难）。

因此本篇把问题改写为：**三套神话各自提供了什么样的"共同过去"，而三套社会又分别取用了其中的哪一部分？**

## 二、中国神话中对人的想象：人是可塑的，处在关系之中

### 2.1 核心意象

| 神话素材 | 对人的隐含设定 |
|---|---|
| 盘古分判阴阳，清浊二气各得其位 | 世界有位置，人也应各得其位；混乱与失序是"气"失衡，可被矫正 |
| 大禹治水：鲧堵而败、禹疏而成 | 人能通过改变方法改变自然；功业是可积累的，且有正确与错误之分 |
| 女娲造人、以石补天 | 人是可被"造"、可被"修补"的；造物者与人类共享创造力 |
| 黄帝与尧舜禹（《史记·五帝本纪》《尚书·尧典》） | 至高的德性可以由无血缘的普通人达到；权力可以通过德行转移 |
| 精卫填海、夸父逐日、刑天舞戚 | 意志的价值高于结果；失败本身可以成为意义的载体 |

综合起来，中国神话中的人**没有不可改变的本质**。儒家进一步把它制度化："人皆可以为尧舜"（《孟子·尽心上》）。在这样的框架里，人的价值是**位置性的**——在关系（父子、君臣、长幼）与名分之中被评价。

### 2.2 社会后果（经由制度中介）

这里必须避免"神话→国民性"的直连。真实的链条要经过制度：

> **神话的"可塑性"设定** → 儒家把"德"与"名分"设为评价主轴（制度中介） → 科举与乡绅体系把出身与德行标准分离（制度中介） → 在此基础上，"人可以改"成为社会流动的合法性叙事 → **可观察后果：** 中国历史上对"改过自新"的容忍度较高，"人"的价值主要由其位置与德行决定，而非由出身或命运决定。

### 2.3 但这套叙事也被用来批判

同一个"人可塑"的神话基底，也支撑了 20 世纪的国民性批判——"国民性是可以改造的"与"人是可以塑成的"是同一个观念的两面。**神话既提供解释，也提供改变的许可。**

## 三、印度神话中对人的想象：人是被前世决定的，但可以退出循环

### 3.1 核心意象

| 神话素材 | 对人的隐含设定 |
|---|---|
| puruṣa 之身的肢体对应（RV 10.90、Śatapatha Brāhmaṇa 1.4.10） | 人的社会位置在宇宙结构里本已注定；反抗等于对抗宇宙 |
| 阎摩与"第一死"（《广森林奥义书》1.3；加耶奥义书 1.3） | 死亡是对无知的报偿；人通过求问获得"死"的教诲 |
| 摩奴的鱼形化身与洪水（《摩诃婆罗多》5.18、《摩鱼往世书》） | 宇宙会周期性毁灭并重启；这一次重启中，正义者被保存 |
| 俱卢之战与《薄伽梵歌》 | 苦难由自己的行为生成；义务高于情感 |
| 虔信（bhakti）叙事：黑天降世、牧牛郎的故事 | 神主动寻找人；人与神的距离可以被跨越 |

综合起来，印度神话中的人**被因果链定义，同时被许诺一条出口**。业（karma）规定了处境，苦行与虔信（还有后来的佛教、耆那教）提供脱离循环的路径。

### 3.2 社会后果

> **神话的"业—报"设定** → 种姓秩序被解释为宇宙性事实（制度中介：婆罗门文本集团与祭祀经济） → 任何秩序挑战都必须在神话内部进行 → **可观察后果：** 印度近现代最激烈的社会变革运动，几乎全部以**提供替代神话**的方式展开：甘地以"非暴力（ahimsa）"重构业、Ambedkar 在《毁灭种姓》(The Annihilation of Caste, 1936) 中公开宣布不再讲授《薄伽梵歌》、达罗毗荼运动以神话人物为旗、佛教与耆那教本身就是另一套创世与救赎叙事。**神话成为社会变革的战场，而不是变革之外的背景。**

这是本篇最值得强调的一条：**在印度，神话的社会功能不是"解释为什么这样"，而是"任何要改变什么的人，都必须先在这里作战"。**

## 四、欧洲神话中对人的想象：人是有限的，荣誉是唯一的补偿

### 4.1 核心意象

| 神话素材 | 对人的隐含设定 |
|---|---|
| 《神谱》的弑父循环 | 秩序建立在暴力之上；没有任何一代能免于被推翻 |
| 普罗米修斯、西西弗斯、塔耳塔洛斯 | 越界必受罚，且罚无止境；人有意志，但没有豁免权 |
| 阿喀琉斯的两难（女神在《伊利亚特》1.424 起的话语） | 人的价值在于行动本身与其被记住的方式，而不是在于活多久 |
| 奥德修斯与涅里托斯之书：女神给他"既不悲也不喜的死亡" | 命运可以指定死亡的方式，但不可免 |
| 俄狄浦斯解谜 | 越有德性越接近毁灭；智慧与幸福不相容 |

综合起来，欧洲神话中的人**注定失败，但失败的方式决定其价值**。人的定义是"承受者"（受难、受命运、受神意），其唯一的补偿是被记住（kleos）。

### 4.2 社会后果

> **神话的"命运—荣誉"设定** → 在城邦体制下，荣誉由共同体（城邦、家族、观众）授予 → 荷马成为各城邦共同的教育文本（行吟诗人传唱） → 近代民族国家把"民族"设想为一个需要英雄与敌人的共同体 → **可观察后果：** 20 世纪的政治因此反复借用英雄叙事（拿破仑式英雄、民族的祖先、文明的守护神），而 20 世纪的欧洲也反复出现"神话政治"的滥用——纳粹对北欧神话与日耳曼"血统"的征用即为一例。

安德森所说的"同源的过去"在这里被放大为"共同的历史使命"。神话在这里的功能是**提供可被不断改写的英雄脚本**。

## 五、三种"对人的想象"对照

| | 中国 | 印度 | 欧洲 |
|---|---|---|---|
| 人是什么 | 关系中可被塑造的位置 | 因果链中的既定处境 | 有限、易受伤害的个体 |
| 人的最高可能 | 成德（人皆可以为尧舜） | 解脱（脱离轮转） | 荣誉（被记住） |
| 人的主要局限 | 名分与时机的限制 | 前世（karma） | 命运（moira）与神意 |
| 神话提供的出口 | 秩序中的位置（名分） | 轮回的终点（mokṣa） | 记忆（kleos，无实际补偿） |
| 失败的意义 | 德行未被识（"有德而不见用"） | 未能守住自己的法 | 命运无法逃脱 |
| 社会变革的常见路径 | 通过"德"的重新评价实现 | 通过**另立神话**实现 | 通过**重新编写**既有叙事实现 |
| 著名误用 | 儒家的"性善"被读成民族天性 | "印度人宿命"成为殖民话语 | "英雄民族"论与 20 世纪神话政治 |

## 六、因果链小结（本篇的核心命题）

一个可用的因果链，必须包含三个必要环节，缺一不可：

1. **原因（社会条件）**：特定的生态、经济、政治结构提出了特定的生存与组织难题。
2. **机制（制度中介）**：某个制度把神话资源固定下来并反复使用——中国的儒家礼制与史书、印度婆罗门文本集团与祭祀经济、欧洲的城邦体制与荷马教育。
3. **结果（可观察后果）**：留下具体的制度、文本或行为模式。

**缺了第 2 环，"神话造成国民性"就是伪因果。** 这也是为什么同一个神话在不同历史时期可以产生完全相反的社会效果：同一个大禹故事，在战国是圣王典范，在晚清可以是变革符号，在当代可以是文化自信的载体。

## 七、边界与反例

- **反例 1：中国神话并不只有"可塑的人"。** 精卫、夸父、刑天塑造的是**执拗到近乎自毁的人**；共工、蚩尤是纯粹的强力者。一套神话内部本就有多种"人"。
- **反例 2：印度神话中的"命运"并非宿命论。** 业是可改变行为以改变来世的机制；"你能修改你的未来"（摩诃婆罗多的经典命题）是主流教义。把它读成"印度人接受命运"是外部误读。
- **反例 3：欧洲神话中的"命运"并非宿命论。** 俄狄浦斯、赫拉克勒斯、阿喀琉斯都在与必然性搏斗；英雄的价值正来自搏斗。希腊人自己写悲剧，正是为了反对把悲剧读成宿命。
- **反例 4（最重要）：三地当代人都持有完全不同的"民族性"自述。** 中国当代自我描述强调"文明连续性"与"整体性"；印度自我描述常强调"多样性、灵性与世俗共和的平衡"；欧洲自我描述强调"多样性、历史纠错与法治"。这些描述与本文所述神话传统有渊源，但**已被 19–21 世纪的政治与学术重新写过**——这本身就证明神话不是国民性的底片。
- **方法提醒**：本文所有关于"社会后果"的段落都标注了制度中介，因为这是唯一能把"神话影响"与"结构决定"区分开来的环节。任何跳过它的论证（包括大量民族性格流行读物）都是把相关当成了因果。
