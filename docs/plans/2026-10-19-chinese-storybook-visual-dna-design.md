# 中式静观叙事视频风格设计

## 目标

为本项目建立可跨视频复用的频道叙事语法，服务于 3–8 分钟的中文叙事视频。频道语法统一单幅构图、旁白、色彩底盘、文字系统和轻动画；每支视频锁定一种完整画风，全片不切换。本次《玄武门》样片锁定工笔。

核心体验是：观众听一个有“说书感”的故事，同时观看一幅幅克制、完整、可停留的画。单幅画承载一个叙事瞬间；动画极轻；角色设定通过角色圣经逐步沉淀为核心资产。

## 设计方向

采用固定的频道叙事语法，但不在同一支视频里混切不同画风。每支视频可选择一种画风并全片锁定；本次《玄武门》样片全片采用工笔的线描、设色和细节处理。其他参考只可帮助人物造型、叙事清晰度或镜头构图；不能变成某几个场景独立的水墨、木刻或其他画种效果。后续视频可选择其他单一画风，同时沿用频道叙事、构图、旁白和动画规则。

风格暂名为“静观式中式叙事插画”。名称可在品牌命名阶段调整，不影响下列视觉规则。

## 1. 视觉 DNA

### 本片画风锁定：淡彩工笔

- 全片维持统一的淡彩工笔线描、设色、材质和细节密度。人物、建筑、山水、图解插页使用同一画风。
- 线描清楚而克制，衣纹、面容和器物细节有选择地刻画；细节集中在视觉焦点，远景保持简洁。
- 色彩采用低饱和的分层设色，纸色和墨色保持稳定；浓重颜色只作少量强调。
- 人物比例和年代服饰保持可信，镜头采用新中式电影构图；这些是造型和构图要求，不改变工笔画面质感。
- 雾、远山和夜色也以工笔设色方式处理，避免单独切成水墨画效果。

每镜只设一个主要焦点。画面以完整的单幅插画呈现，每幅画对应一个叙事瞬间。

整屏地图、路线图或关系图称为“图解插页”。每集最多使用一幅，并且只在空间或关系难以通过叙事画和旁白讲清时使用。它占满单一画面，不与人物场景拼成多格版面。

### 色彩

旧纸色、墨黑、烟灰和整体低饱和度构成跨集固定的色彩底盘。青灰、石青、赭黄等辅助色可根据时代、地点和光线调整。每幅画最多突出一种强调色，朱砂可作为候选。相邻场景之间的色调变化应有光线或叙事情境依据。

建议先以一组颜色建立风格测试：旧纸 `#E8E0CF`、墨黑 `#242521`、烟灰 `#77786F` 为底盘；青灰 `#657B78` 和赭黄 `#B38A56` 为可按场景调整的辅助色；朱砂 `#A54A3D` 为候选强调色。它们是设计起点，需由首批风格样片校准。

### 构图

- 使用横向 16:9 画面。
- 第一镜直接呈现开场悬念的工笔叙事画；片名以无衬线字短暂叠在画面留白处后淡出，不另设独立片头卡。
- 不设置独立章节卡；确有必要提示段落转换时，章节名才短暂叠加在叙事画的留白处。
- 以单一主体或视觉意象作为焦点，避免一镜塞入多个互相竞争的事件。
- 使用前景、中景、远景形成空间层次。
- 通过全景、中景和近景建立镜头变化。
- 底部预留字幕安全区；人物面部与重要道具避开该区域。
- 全片显示与旁白同步的完整字幕；每屏最多两行，保持易读，不重复显示场景标题。字幕无底板，使用墨色无衬线字和轻微浅色描边适应画面变化。
- 保持画面留白，让观众有时间观看细节。
- 主体镜头不叠加右下角品牌角标。频道标记在品牌身份确定后，放在片尾或单独的短签名画面。
- 片名、章节标题和字幕统一使用无衬线字体；通过字号、字重和留白建立层级。书法字不进入正式文字系统。
- 《玄武门》样片统一使用 `paper-light` 主题，并沿用其无衬线字体配置；字体家族仍通过主题配置保留调整空间。

## 2. 叙事与旁白

旁白采用沉静、清楚、带停顿的讲述口吻。讲述者带观众进入故事，逐步交代背景、人物处境、选择和后果。语言亲近、准确，有讲述感；古风表达只在确有语境需要时使用。

频道使用同一位讲述者，并保持稳定的声音特征、语速和停顿习惯。人物对白由讲述者转述，不切换成多角色配音。配音优先使用 Voicebox 提供的同一音色；首次样片中选定具体 profile 并记录。Voicebox 暂不可用时，沿用项目支持的配音回退路径，并保留声音连续性。

### 单集结构

1. **开场立悬念**：从一个具体人物、物件或瞬间切入，提出故事的核心疑问。
2. **交代时地人**：建立年代、地点和人物关系。
3. **铺陈局势**：说明事情如何走到关键时刻，以及人物面临的处境。
4. **选择与转折**：围绕人物决定推进故事，在关键转折前后留停顿。
5. **回到开场意象**：回应最初的问题，以一个画面或余味收尾。

每段旁白承担一个主要信息。长句拆分成易听懂的短句。首次出现的人名、地点和关键概念要说清楚。旁白留出停顿，让画面参与叙事。写稿采用项目现有中文语速范围的低端，目标约每分钟 220–240 字；旁白通常占成片时长约 55–70%，其余时间用于停顿、转场和观看画面。

### 时长与密度

常用成片时长为 4–6 分钟。3 分钟适合一个核心问题或单一事件；接近 8 分钟时，需要更完整的人物弧线或多次叙事转折。

| 成片时长 | 旁白字数参考 | 画面数量参考 |
| --- | ---: | ---: |
| 3 分钟 | 约 360–500 字 | 12–18 幅 |
| 5 分钟 | 约 600–840 字 | 20–28 幅 |
| 8 分钟 | 约 970–1,340 字 | 30–40 幅 |

字数范围按每分钟 220–240 字、旁白占成片 55–70%估算，仅供起稿使用。最终时长由配音速度、停顿和片头片尾共同决定。每幅画默认停留 8–15 秒；短镜头可用于强调或信息切换，连续静态画面可延长至 20 秒。该范围是可调的风格基准，按故事需要调整，不是固定限制。

## 3. 极轻动画

画面静止是默认状态。动画只为时间感或叙事重点服务，每镜最多采用一种轻微变化。

初始节奏参考：约 80% 镜头完全静止、15% 镜头缓慢推进、最多 5% 镜头包含环境微动。它们是可调整的样片基准，不要求每集机械凑足比例；可根据故事和样片观感微调。

- 缓慢推进：8–15 秒内画面缩放约 1–2%。
- 平移：只在引导视线时使用，速度保持很低。
- 环境微动：雨丝缓落、灯笼轻摆、烛火微颤、薄雾缓行等，每镜只选一种。
- 人物、山水和房屋保持静止。
- 转场以直接切换为主；需要柔和衔接时使用短淡入淡出。

音乐托住氛围，保持克制。雨声、风声、脚步声和远处钟声等环境音，仅在具有叙事作用时使用。

频道形成固定的声音底色：低存在感、无明显节拍的持续配乐；环境声按画面需要少量使用。单集可以更换曲目，但不以节拍推动剪辑，也不盖过讲述者。

## 4. 角色圣经

角色圣经是跨视频维护的角色资产库。档案保存角色的稳定视觉设定、经确认的参考图和版本历史；每个场景沿用核心设定，再增加当前情境所需的服饰、动作和情绪信息。

### 角色档案字段

- **身份**：稳定的角色 ID、姓名、时代、地域、身份和故事职责。
- **外形锚点**：身形比例、脸型、眉眼、发式、胡须和标志性姿态。
- **外观变体**：同一角色在不同年龄、时期或身份下的服饰与外观记录；所有变体共用角色 ID，并保留可辨认的身份锚点。
- **画风参考**：身份设定与具体画风分开。每个画风各自保存候选和正式参考图；更换画风时沿用角色身份锚点，并为新画风单独生成、审核参考。
- **服饰与道具**：常服、礼服或战时装束，以及一至两件识别性道具。
- **依据与推断**：为脸貌、服饰、道具等视觉设定分别标注史料依据或美术推断，并记录已知来源。资料不足时将细节保留为创作选择，不将其表述为确定史实。
- **表演范围**：常见神态、适用动作和需要避免的造型偏差。
- **参考图**：角色图分候选和正式版本；记录版本、审核状态和适用时期。

建议共享资产目录为 `assets/characters/<character-id>/`，初期包括结构化角色设定、人工确认的参考图和版本说明。角色 ID 在脚本、分镜和资产中保持一致。

### 积累流程

1. 每集主角先创建角色 ID 和轻量档案；跨集复用或具有突出辨识价值时，再制作完整参考图。路人和背景人物不建档。
2. 完整档案先生成当前画风的候选参考图；人工检查角色联系表并批准后，才能作为该画风下的跨集正式版本复用。
3. 每次出场沿用角色核心描述和对应时期的外观变体，只添加场景特有信息。
4. 出片前整理角色联系表，检查轮廓、脸型、发式、体态、服饰和标志道具等关键视觉锚点。
5. 关键视觉锚点明显漂移时退回重生成；细微五官差异在当前阶段可以接受。
6. 有明确剧情或史实理由时才更新底稿；新图先作为候选，经人工批准后成为正式版本，并保留旧版本。

角色档案从每集主角开始积累。跨集复用或具有突出辨识价值的角色升级为完整档案；首批视频验证流程后，再扩展到常驻角色、配角和跨集人物关系。

角色圣经分为身份层和画风表现层：身份层保存角色身份、史料依据、美术推断和外观变体；画风表现层保存该角色在各个画风中的候选与正式参考。角色 ID 跨画风保持不变。

## 5. 项目现状与实现边界

- 项目已有 `editorial`、`ink-wash` 等图片风格预设，可作为风格系统的参考基础。
- 当前 Motion Agent 规定每个镜头输出 2–5 个动画，与本设计的“每镜最多一种轻微变化”不一致。后续实现应为本风格设置单独的运动约束。
- 当前 Motion Agent 已允许 `camera` 动画类型，可用于缓慢推进。
- 当前图片生成流程不能把角色参考图作为图像条件输入。角色圣经可先用于人工审查和文字提示的一致性管理；跨场景脸部细节可能变化，因此先按轮廓、脸型、发式、体态、服饰和标志道具等关键视觉锚点验收。关键锚点明显漂移时退回重生成，细微五官差异可以接受。
- 当前视觉分类器没有专用地图组件；`map` 场景会落到通用插画路径。图片生成规范不允许模型绘制可读文字，因此地图地名若需准确显示，必须由渲染器另行绘制。
- 当前分镜流程强制第一场景使用独立 `Title` 组件，现有组件以主题色纯背景呈现标题。后续实现需允许将片名叠加在第一幅叙事画上，并在短暂显示后淡出。
- 雨丝、灯笼等局部动画需要图像提供可独立控制的图层或遮罩。若输入只有单张合成图，则先使用镜头推进或保持静止。

## 6. 风格验收标准

首批风格样片按以下标准人工评审：

1. 每个镜头都能读作一幅完整画面，焦点明确，字幕区不遮挡关键信息；图解插页每集最多一幅。
2. 本片始终保持淡彩工笔；其他画种只可作为人物造型、叙事清晰度或构图参考，不改变画面表面风格。
3. 旁白能独立听懂，也能与画面共同推进故事；关键转折有足够停顿。
4. 多数镜头保持静止；有动画的镜头只出现一种低幅度变化。
5. 同一角色跨镜头的轮廓、脸型、发式、体态、服饰和标志道具等关键视觉锚点稳定；明显漂移会被退回，细微五官差异可接受。
6. 成片时长落在 3–8 分钟内，旁白长度和画面停留时间与故事密度相符。

## 7. 建议的验证顺序

1. 以现有 `projects/玄武门/article.md` 作为首支风格样片。它是 5 分钟的唐代历史题材，已有时代设定和分镜。
2. 为李世民建立一个 `li_shimin` 角色 ID，包含“青年秦王”和“后期皇帝”两个工笔外观变体；李渊等其他角色只作单集角色，不进入共享角色库。
3. 生成前为相关分镜标注明确角色身份和外观变体，再制作候选参考图；检查同一角色在不同景别中的视觉稳定性。
4. 将 scene-08 的征战路线图作为本集唯一一幅图解插页；地图也采用淡彩工笔，只绘路线、山河和标记点，不显示可读地名，城市名称由旁白讲述。地图为简化示意，主要山河和路线方向依据史料核对，不画比例尺和细碎地形。其余镜头使用叙事画。
5. 先评审静帧：确认淡彩工笔线描、设色、人物造型和字幕安全区。
6. 在通过的静帧上分别试验静止、慢推和一种环境微动；参考图经人工批准后再成为正式版本。
7. 根据评审记录更新频道视觉规则，再扩展到其他题材和后续视频。
