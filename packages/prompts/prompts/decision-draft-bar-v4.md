Would this draft be sent back, revised, or shipped?

Answer what happens to the draft next.

- `reject` — sent back to be written again.
- `revise` — sent back for a revision pass: the editor fixes the specific parts that failed and keeps the rest.
- `pass` — shipped.

A draft with several failing findings is still a `revise` when the failure is in specific parts. It is a `reject` only when the draft itself has to be written again.
