# Review criteria added by channel profile: `chinese-storybook`

Judge the draft against these IN ADDITION to the standard rubric. Each
failure is an ordinary weighted finding — report the measured number, not a
style opinion.

## Pacing

- **Delivery rate.** Count the Chinese characters in all scene narration,
  divide by (`duration_target_sec` / 60). Outside **220–240 characters per
  minute** is a finding. State the measured rate.
- **Narration share.** Spoken characters against total runtime must land in
  **55–70%**. Outside that is a finding. State the measured share.

## Voice

- **Stagey dialogue.** Any character speech written as a quotation, or any
  writing that performs a character (stage directions, a named speaking
  register, "X said loudly"), is a finding. This channel relays dialogue
  through the narrator only.
- **Split personality.** A second narrator voice ("imagine", "as a
  developer", text that addresses the viewer directly) is a finding.

## Shape

- **Arc.** The film must show 悬念 → 背景 → 局势 → 选择/转折 → 回扣开场
  once through. A missing stage, or stages out of order, is a finding.
- **Uncommitted engine.** Identify which of the seven basic plots
  (斩妖除魔, 从穷困到富有, 探寻, 远行与回归, 喜剧, 悲剧, 重生) the film
  actually runs on. If no single engine owns the turning point, or the
  ending contradicts the engine (a 悲剧 curve rescued in the last scene,
  a 重生 that ends still frozen, a 从穷困到富有 whose middle loss is one
  sentence), that is a finding. Name the engine you identified and the
  beat that betrays it.
- **Filler.** A scene that only restates the previous one, or narration
  written to fill a scene's duration, is a finding.
- **Channel violations.** Calls to action, subscribe prompts or a channel
  sign-off in the spoken text are findings.

## AI 腔 (machine prose)

Judge the prose itself. Report counts and measurements, not impressions.

- **Banned phrases.** Count every occurrence of the drafter block's banned
  list (在当今……的时代, 随着……的发展, 综上所述, 总而言之, 值得注意的是,
  让我们一起, 这不仅……更……, 赋能, 抓手, 闭环, 痛点, 深度解析, 重塑,
  矩阵, 不言而喻, 毋庸置疑, 众所周知). Any occurrence is a finding.
  State the count and quote the first one.
- **Canned transitions.** Count transitions that announce a structure
  instead of carrying a cause (「但那只是开始」, 「真正的转折点在后面」,
  「故事还有另一部分」, "that's just the beginning", "the real turning
  point came later"). More than one is a finding.
- **Scaffolding.** A 首先/其次/最后 run, or a paragraph that opens by
  restating the previous paragraph, is a finding.
- **Even rhythm.** Measure the sentence lengths of the narration. If
  every sentence falls within three characters of the mean, that is a
  finding — state the mean, the spread, and the longest sentence. A
  spread wider than half the mean is normal and is not a finding.
- **Forced elevation.** An ending that sums up the film's meaning
  instead of its last concrete beat (「这就是……的意义」, 「未来正在到来」)
  is a finding.
- **Fabricated experience.** A first-hand anecdote the sources do not
  support (「我当时……」, "in my experience") is a finding, and a critical
  one when it carries a claim.
