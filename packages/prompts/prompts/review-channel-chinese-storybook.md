# Review criteria added by channel profile: `chinese-storybook`

Judge the draft against these IN ADDITION to the standard rubric. Each
failure is an ordinary weighted finding — report the measured number, not a
style opinion.

## Pacing

- **Delivery rate.** Count the Chinese characters in all scene narration,
  divide by (`duration_target_sec` / 60). Outside **220–240 characters per
  minute** is a finding. State the measured rate.
- **Narration share.** Spoken characters against total runtime must land in
  **55–70%**. Outside that is a finding. State the measured share.

## Voice

- **Stagey dialogue.** Any character speech written as a quotation, or any
  writing that performs a character (stage directions, a named speaking
  register, "X said loudly"), is a finding. This channel relays dialogue
  through the narrator only.
- **Split personality.** A second narrator voice ("imagine", "as a
  developer", text that addresses the viewer directly) is a finding.

## Shape

- **Arc.** The film must show 悬念 → 背景 → 局势 → 选择/转折 → 回扣开场
  once through. A missing stage, or stages out of order, is a finding.
- **Filler.** A scene that only restates the previous one, or narration
  written to fill a scene's duration, is a finding.
- **Channel violations.** Calls to action, subscribe prompts or a channel
  sign-off in the spoken text are findings.
